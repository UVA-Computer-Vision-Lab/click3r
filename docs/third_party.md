# Third-party sources and assets

## Code

`third_party/dust3r/` holds DUSt3R and CroCo under CC BY-NC-SA 4.0, with our changes listed in its [README](../third_party/dust3r/README.md#modifications). Code adapted from them elsewhere in the repository stays under that license.

Other adapted files state their source and license in the file header.

## Demo images

The images in `assets/examples/` and the README animation `assets/teaser.webp` come from the datasets below and stay under those datasets' licenses. We converted the example images to PNG and/or center-cropped and resized them; the animation shows two CA-1M images, resized, next to Click3R's reconstruction of them.

| Example | Attribution | Dataset/asset terms and source |
|---|---|---|
| Bicycle, Cellphone, Suitcase, Toaster, Toy truck, Umbrella, Cake, Teddy bear, Handbag, Smartphone | Meta and CO3D contributors; Reizenstein et al., *Common Objects in 3D*, ICCV 2021 | [CO3D, CC BY-NC 4.0](https://ai.meta.com/datasets/co3d-downloads/) |
| Railing, Aerial houses, Town rooftops, Village and pond | Yao et al., *BlendedMVS: A Large-scale Dataset for Generalized Multi-view Stereo Networks*, CVPR 2020 | [BlendedMVS, CC BY 4.0](https://github.com/YoYo000/BlendedMVS#license) |
| Breakfast room | Wig42, scene creator; Azinović et al., *Neural RGB-D Surface Reconstruction*, CVPR 2022, rendered dataset | [Original scene, CC BY](https://blendswap.com/blend/13363); [dataset attribution](https://github.com/dazinovic/neural-rgbd-surface-reconstruction) |
| Relief, Courtyard | Schöps et al., *A Multi-View Stereo Benchmark with High-Resolution Images and Multi-Camera Videos*, CVPR 2017 | [ETH3D, CC BY-NC-SA 4.0](https://www.eth3d.net/documentation) |
| Scribbled box; Brick building model; Building model, top view; Poster box; Rabbit figurine with ear muffs | Jensen et al., *Large Scale Multi-view Stereopsis Evaluation*, CVPR 2014 | [DTU Robot Image Data, citeware](https://roboimagedata.compute.dtu.dk/) |
| Flower pot | Xia et al., *RGBD Objects in the Wild: Scaling Real-World 3D Object Learning from RGB-D Videos*, CVPR 2024 | [WildRGB-D, MIT](https://github.com/wildrgbd/wildrgbd/blob/main/LICENSE) |
| README animation (poster on a wooden floor) | Apple; Lazarow et al., *Cubify Anything: Scaling Indoor 3D Object Detection*, CVPR 2025 (CA-1M) | [CA-1M, CC BY-NC-ND 4.0](https://github.com/apple/ml-cubifyanything#license) |
