Click3R Interactive Stereo 3D Reconstruction with Sparse Correspondence Clicks

A few correspondence clicks correct a feed-forward 3D reconstruction, in a single forward pass.

Hao Gu*† Jin Yao* Zezhou Cheng

University of Virginia

* Equal contribution   † Project lead

arXiv soon Code Demo Weights Data

Overview

Feed-forward 3D reconstruction, made correctable with a few clicks.

Feed-forward models such as DUSt3R reconstruct a scene from two images in a single network pass, but their prediction is final: when the geometry is wrong, nothing can correct it. Click3R takes a few user-provided correspondence clicks as additional input and predicts corrected geometry in the same single pass, with no test-time fine-tuning or optimization. We also release Hard3DBench, a benchmark of image pairs and five-view sets selected to expose failures of current models.

+9.8mAA@30 With 8 clicks, on unseen hard pairs Click3R with 8 ground-truth clicks scores 62.4, vs 52.6 for DUSt3R retrained on the same data. Tested on Hard3DBench pairs from 5 datasets unseen in training.
+20.5mAA@30 With real user clicks, on unseen hard pairs Click3R with a human annotator's clicks (3.8 clicks per image pair on average) scores 56.2, vs 35.7 for DUSt3R retrained on the same data.
+6.4%parameters A lightweight adapter on top of DUSt3R A 34.1M-parameter adapter added to DUSt3R's 532.3M, bypassed when no clicks are supplied.

Method

Correspondence clicks are injected into the decoder through a lightweight adapter.

Click3R takes an image pair and an optional set of sparse point correspondences, and predicts dense 3D pointmaps for both views in a single forward pass. The base model and adapter are trained jointly end-to-end on correspondences simulated from ground-truth geometry, yielding a single model that supports a flexible number of clicks, from none up to 12.

  1. 01

    Shared ViT encoder

    A shared ViT-Large encoder processes each image independently into patch tokens.

  2. 02

    Correspondence tokenizer

    Each correspondence point is tokenized as a Fourier positional encoding of its 2D location, plus learnable image ID and pair ID embeddings that mark its view and link it to its matching point.

  3. 03

    Point correspondence adapter

    A two-way attention adapter, one per view, exchanges information between correspondence tokens and image tokens and updates the image features before decoding.

  4. 04

    Asymmetric decoder and prediction heads

    The asymmetric decoder processes the updated features with cross-attention between the two views, and the prediction heads output 3D pointmaps and confidence maps.

Hard3DBench

A benchmark that exposes the failure modes of feed-forward 3D reconstruction

Hard3DBench includes 2-view and 5-view settings, with challenging samples from held-out splits of the training datasets and from datasets unseen in training. Each image pair is labeled with its failure modes.
